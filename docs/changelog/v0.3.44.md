### 2026-05-19

- **carousel-slider 마지막 슬라이드 중앙 정렬 수정**
  - `.slider-wrapper` padding `max(0px, calc(50% - 512px))` → `max(80px, calc(50% - 512px))`
  - `goToSlide` 수동 scroll 계산(`container.scrollTo`) → `scrollIntoView({ inline: 'center' })` 전환
  - 기존 방식: `idx * (item.offsetWidth + 24)` 계산이 Windows scrollbar 폭 + CSS sub-pixel 렌더링 오차로 snap point에 1–2px 못 미침 → 마지막 슬라이드 미세 어긋남
  - `scrollIntoView({ behavior: 'smooth', block: 'nearest', inline: 'center' })`: 브라우저가 실제 레이아웃 기반으로 정확한 scroll 위치를 계산 → 모든 환경에서 정확한 중앙 정렬
