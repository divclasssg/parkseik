## 배경

v0.3.21에서 외장 1080p(DPR=1) 모니터 깨짐을 해결한다며 hi/lo + DPR 분기를 도입(`final_prototype_0{1,2,3}_lo.mp4`, 소스÷2 해상도). DPR=1 + 최대 표시 폭에서 1:1 매핑된다는 의도였으나, 사용자(외장 1080p · OS 스케일 100%)가 영상 안 **글씨가 다 깨져 보임**을 보고.

진단:

1. **1:1 매핑은 최대 폭에서만 성립** — `.section-hero { height: calc(100svh - 108px) }` 플렉스 레이아웃 때문에 실제 표시 폭은 디자인 최대(660 / 1512 CSS px)에 못 미침. 1080p viewport 기준 phone 약 280 CSS px, monitor 약 1000 CSS px. 즉 lo(660 · 1512)를 다시 한 번 브라우저가 다운스케일.
2. **lo 자체에 사전 디테일 손실 누적** — 소스÷2 lanczos 다운샘플 + 4:2:0 크로마 서브샘플링 + H.264 자연영상용 양자화로 글자 엣지가 인코딩 단계에서 이미 뭉개짐. 이후 브라우저 다운스케일로는 복원 불가.
3. **Retina(DPR=2)는 hi 단일 다운스케일이라 글자 디테일 보존** — 같은 표시 CSS px라도 hi에서 시작하면 루마 4× · 크로마 8× 디테일이 살아 있음.

→ "저화질 모니터에서만 깨짐"의 본질은 lo 인코딩 자체의 글자 충실도 손실. 해결은 lo 폐기 + hi 단일 서빙. 3개 hi 합 약 6.8 MB는 portfolio hero 트레이드오프로 수용.
