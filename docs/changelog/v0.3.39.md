# v0.3.39 — /projects/eum 카드 마크업 구조 재설계

## 작업한 내역

- `2026-05-19` `src/app/projects/eum/page.js`, `src/app/projects/_style/projects.style.scss`, `src/app/projects/eum/_style/projects.eum.scss` — 카드 마크업 구조 재설계 및 클래스명 정리

## 변경 내용

### 구조 평탄화
- 루트 컨테이너를 `.card-content`(Type 1·3)와 `.card-callout-wrapper`(Type 2·4) 두 종류에서 `.card-group` 단일 클래스로 통합
- `.card-wrapper`, `.card-grid-wrapper` 불필요 wrapper 삭제 — 카드까지 도달하는 depth 2–4단계 → 0–1단계로 축소

### 클래스명 정리
| 이전 | 이후 |
|---|---|
| `.card-content` / `.card-callout-wrapper` | `.card-group` |
| `.card-eyebrow` | `.card-group-label` |
| `.card-wrapper`, `.card-grid-wrapper` | 삭제 |
| `.card-column-2` | `.card-group.col-2` |
| `.card-column-3` | `.card-group.col-3` |
| `.card-set-full-bleed` | `.card.card-bleed` |
| `.card` (tile) | `.card.card-tile` |
| `.card-callout` | `.card` |
| `.card-callout-white` | `.card.card-white` |
| `.content-body` / `.card-body` | `.card-body` (통합) |
| `.content-image` / `.card-image` | `.card-media` (통합) |

### 접근성
- `visuallyhidden` heading 태그(h3/h4) → `.card-group`의 `aria-label` 속성으로 교체 (Type 2·3·4)

### CSS
- `.card-callout` 스타일이 `.card-column-2`와 `.card-column-3` 안에 중복 선언되어 있던 문제 해소 — `.card-group .card` 단일 규칙으로 통합
- `display: -ms-grid; display: -moz-grid;` 미사용 벤더 접두사 제거

## 배경

어드민 관점에서 카드 하나를 추가·수정할 때 두 종류의 루트 컨테이너 중 무엇을 골라야 하는지, 몇 단계 wrapper 안에 넣어야 하는지 판단해야 하는 구조적 불편 해소.
