# v0.3.26 — /projects/eum 히어로 animated WebP를 lossless로 재인코딩

## 작업한 내역

- `2026-05-18` `eum/videos/hero/final_prototype_0{1,2,3}.webp` (R2) — v0.3.25 옵션(`-q 95 -mixed -sharp_yuv -m 6`)도 화질 부족이라는 사용자 피드백 → `img2webp -lossless -m 6 -d 42`로 무손실 재인코딩하여 R2 덮어쓰기. 결과: 01 3.1MB → 4.6MB, 02 3.9MB → 6.0MB, 03 1.4MB → 2.0MB (총 11MB → 15MB). 새 ETag로 캐시 무효화 확인.

## 배경

v0.3.25에서 lossy q95 + mixed + sharp_yuv 조합으로 약 1.9배 화질 향상했으나 사용자가 "부족" 응답. lossy 압축 자체의 한계 → **lossless** 모드로 전환. 픽셀 단위 완벽 보존이라 텍스트·아이콘이 원본과 동일 수준으로 렌더링.

`-m 6` (최고 압축 효율)로 lossless여도 파일 크기를 최소화. fps 24·해상도(영상별 lo와 동일)는 유지.

코드 변경 없음. 사용자는 강력 새로고침으로 새 화질 확인.
