# v0.3.35 — /projects/eum hero video-wrapper max-width 1200px

## 작업한 내역

- `2026-05-19` `src/app/projects/eum/_style/projects.eum.scss` — `.video-wrapper`에 `max-width: 1200px` 추가, `margin: 0 auto`로 수평 중앙 정렬 적용. 와이드 스크린(1200px 초과)에서 video-wrapper가 1200px로 캡되어 중앙에 고정됨.
- `2026-05-19` `src/app/projects/eum/_style/projects.eum.scss` — `.monitor-frame`을 height-driven에서 width-driven으로 전환. `width: 100%; height: auto;` 추가(공통 `width: auto; height: 100%` 오버라이드). `.monitor-frame-screen`도 `width: 100%; height: auto;`로 변경. wrapper max-width 도입 시 screen 자연 너비(height × 3024/1964)가 frame content를 초과해 넘쳐나는 버그 수정.

## 배경

1440px+ 뷰포트에서 video-wrapper가 전체 폭을 차지해 phone 프레임이 지나치게 우측으로 밀리는 문제. `inset: 48px 0` + `max-width: 1200px` + `margin: 0 auto` 조합으로 절대 위치 요소를 최대 1200px로 캡하고 중앙 정렬.

monitor-frame은 기존에 `height: 100%(wrapper) → aspect-ratio → width` 방식(height-driven)으로 wrapper 높이 전체를 채웠으나, wrapper max-width 도입 후 frame content width(1200-24=1176px)보다 큰 자연 너비를 screen이 가지려 할 때 overflow 발생. `width: 100%(wrapper) → screen width: 100% → aspect-ratio로 height 결정` 방식(width-driven)으로 전환해 overflow 제거.
