## 작업한 내역

- `2026-05-17` `src/app/projects/_style/projects.style.scss` 수정 — `.section-hero { height: calc(100svh - 44px) }`이 globalnav(44px)만 차감하고 **localnav(64px)를 빠뜨려** main의 가용 영역(`calc(100svh - 44 - 64)`)을 64px 초과하던 버그 정정. `height: calc(100svh - 44px - 64px)`로 변경하여 main 안에 정확히 fit. 동시에 `display: flex; flex-direction: column` 추가하여 안쪽 wrapper가 flex로 남는 vertical 공간을 자동 차지하도록 layout 모드 전환
- `2026-05-17` `src/app/projects/eum/_style/projects.eum.scss` 수정 — `.video-wrapper`의 고정 `height: calc(100svh - 180px)` 제거(사용자의 추정값이었으나 실제 hero padding 160 + section-content ≈180 + margin 32 = 372px 오버헤드를 빠뜨려 hero 박스를 추가 초과). `flex: 1 1 auto; min-height: 0`로 교체 → wrapper가 hero 내부 남는 공간을 자동 차지, 어떤 viewport·section-content 크기에도 100svh fit 보장. `min-height: 0`은 flex column에서 자식 콘텐츠가 컨테이너보다 클 때 축소를 허용하기 위해 필수
- 결과 (1080 viewport): wrapper 자동 높이 ≈ 600px (이전 900에서 33% 축소). phone 프레임 폭 약 294 CSS px ([[feedback-retina-media-cap]] 안전 — 소스 1320 ÷ 2 = 660 한도 내). 모니터 프레임은 wrapper 폭이 충분해 1024 max에서 자동 분배
- `2026-05-17` fix(SCSS) `src/app/_style/_common.scss` `.section-content` — flex column 부모(이번 변경으로 `.section-hero`에 `display: flex` 추가됨) 안에서 `margin: 0 auto`가 `align-items: stretch`를 무효화하여 cross-axis(width) 크기가 콘텐츠로 줄어들어 max-width 1024가 무용해지는 증상. 일반 흐름에선 redundant이지만 flex 컨텍스트에선 cross 사이즈 명시가 필요한 `width: 100%`를 추가하여 stretch 의도 복원. 일반 block 컨텍스트엔 무영향
