## 애니메이션 단계 요약 (각 아이템 로컬 진행도 0~1 기준, ITEM_COUNT=4)

| 구간 | 이미지 | 텍스트 |
| --- | --- | --- |
| 0–22% | slide-up + fade-in (첫 자료는 opacity 1 고정) | hidden (y=120px) |
| 22–30% | 정지 (opacity 1) | hidden |
| 30–55% | DIM 전환 (opacity 1 → 0.08) | slide-up + fade-in (y 120→0, op 0→1) |
| 55–82% | DIM 유지 (op 0.08) | HOLD (op 1, 클릭 가능) |
| 82–100% | DIM → 0 + 상향 드리프트 (-3vh) | slide-up + fade-out (y 0→-120px, op 1→0) |

## 모바일 fallback (`@media (max-width: 640px)`)

sticky / absolute / mask / RAF 변환을 모두 무효화하고 4개 아이템을 위에서 아래로 평탄하게 스택. 이미지는 480px 폭 cap으로 압축. 모든 자료가 즉시 노출되어 정보 접근성 보장.

## 디자인 토큰 변환 (portfolio → parkseik)

portfolio는 CSS 변수(`var(--space-24)`, `var(--color-text-tertiary)` 등)를 사용하지만 parkseik은 raw 값 위주. 타이포그래피·간격은 다음과 같이 변환:

- `var(--space-24)` → `24px`
- `var(--color-text-tertiary)` → `#66666f`
- `--localnav-height` → `64px` (parkseik 공통 localnav 높이)
- `--font-family-spoqa` / `--font-family-suit` → 전역 `.main-projects` 의 font-family 상속 (Spoqa Han Sans Neo + SUIT)
