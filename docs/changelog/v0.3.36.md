# v0.3.36 — /projects/eum hero 텍스트 영역 그라데이션 스크림

## 작업한 내역

- `2026-05-19` `src/app/projects/eum/_style/projects.eum.scss` — `.section-hero .hero-body`에 `background: linear-gradient(to bottom, transparent, rgba(255, 255, 255, 0.92))` 추가. 전체 폭이 아닌 텍스트 블록(max-width: 1024px) 영역에만 그라데이션이 적용되도록 범위 한정. 위쪽(영상 쪽)은 투명, 아래쪽(텍스트 기저)은 흰색으로 점진적으로 전환되는 스크림 적용.

## 배경

영상 2번(모니터 프레임)이 텍스트 영역과 겹쳐 가독성이 저해되는 문제. frosted glass(v0.3.33)는 시각 무게·디바이스 잘림 문제로 이미 제거된 전례가 있어, 더 가벼운 대안으로 수직 그라데이션 스크림을 채택. backdrop-filter 없이 GPU 부하 최소화. rgba(255,255,255,0.92)로 완전 불투명 대비 약하게 깔리는 효과.
