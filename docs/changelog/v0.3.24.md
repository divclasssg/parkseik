## 배경

네 차례 시도(v0.3.20~v0.3.23) 후에도 외장 1080p에서 화질이 부족했고, v0.3.23 image slideshow는 디자인 방향(motion 필요)과 어긋난다는 사용자 피드백.

진단 종합:
- video 코덱(H.264)은 빠른 motion 콘텐츠에서 P/B 프레임 양자화 오차가 커 정지·자동재생 모두 흐릿. DPR=1 환경에서 두드러짐.
- 정적 webp slideshow는 화질은 깨끗하나 동영상의 "흐름"이 사라져 사용자 의도 불충족.

해결: image 코덱 기반 animated webp. (a) 자동재생되어 motion 유지 (b) 각 프레임이 image 코덱이라 텍스트/UI 깔끔 (c) `<img>` 하나로 처리되어 video element/디코더 없음(GPU 부담 ↓).

cycle 보장 패턴: 활성 영상의 `<img>` key에 `cycleN` 카운터를 suffix로 붙여 active 전환 시마다 React가 remount → animated webp 0초부터 재생. 비활성 영상은 같은 element 유지하며 opacity 0 → 페이지 첫 진입 시 3개 모두 fetch + 캐시 → 이후 전환 즉시.
