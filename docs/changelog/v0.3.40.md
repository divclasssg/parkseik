# v0.3.40

## 작업한 내역

### 2026-05-19

- **localnav 스크롤 등장·사라짐 애니메이션**
  - 페이지 진입 시 localnav 숨김 (`translateY(calc(-100% - 20px))`)
  - 80px 스크롤 시 `visible` 클래스 토글 → 0.3s cubic-bezier 슬라이드 다운
  - 최상단 복귀 시 다시 슬라이드 업으로 사라짐
  - `useEffect` + passive scroll listener로 구현 (`localnav.js` Client Component 전환)

- **content-expanded-wrapper expand/collapse 애니메이션**
  - 기본값 숨김 (`opacity: 0; visibility: hidden; transform: translate(-50%, -10px)`)
  - "프로젝트 더보기" 클릭 → `open` 클래스 → 0.22s fade + slide-in
  - 닫기(X) 버튼 클릭 → 0.22s fade + slide-out 후 `visibility: hidden`
  - `visibility` transition delay로 애니메이션 종료 후 접근성 처리
  - `aria-expanded` 상태 동기화

- **contentnav smooth scroll + localnav 오프셋**
  - 앵커 링크 클릭 시 `e.preventDefault()` 후 `window.scrollTo({ behavior: "smooth" })`
  - expanded 패널 열림 여부에 따라 오프셋 동적 계산
    - 닫힘: `navRef.offsetHeight + 32px`
    - 열림: `expandedRef.offsetHeight + 32px` (절대 위치 패널 높이 별도 측정)
