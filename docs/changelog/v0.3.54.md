# v0.3.54 — /projects/eum carousel-slider 카드 폭 축소 (이미지 폭 정합)

## 작업한 내역

- `2026-05-20` `src/app/projects/_style/projects.style.scss`
    - `.carousel-slider .slider-wrapper`: padding `max(80px, calc(50% - 512px))` → `max(80px, calc(50% - 348px))`. 첫·마지막 슬라이드 viewport 중앙 정렬 기준 갱신 (slider-item max-width의 절반).
    - `.carousel-slider .slider-wrapper .slider-item`: flex basis `min(calc(100vw - 160px), 1024px)` → `min(calc(100vw - 160px), 696px)`. 카드 max-width를 696px(= 이미지 max 648 + 카드 padding 24×2)로 축소.

## 배경

v0.3.53에서 carousel-slider 3장 슬라이드에 키스크린 이미지(소스 1296×474, 표시 max-width 648 retina cap)를 임베드. 슬라이드 카드는 max 1024px이고 콘텐츠 영역 976px이라, 이미지(648px) 좌·우에 약 164px씩 빈 공간이 남는 시각 불균형이 발생. 카드 폭을 이미지+패딩에 맞춰 축소해 시각 균형 회복.

## 변경 후 매트릭스

| 항목 | 기존 | 변경 |
| --- | --- | --- |
| slider-item 카드 max-width | 1024px | **696px** |
| 카드 콘텐츠 영역 (padding 24×2 제외) | 976px | **648px** |
| slider-visual 이미지 max-width | 648px | 648px (변경 없음) |
| 이미지 좌·우 카드 내 여백 | 약 164px × 2 | **0 (정확히 채움)** |
| 본문 텍스트 영역 | 976px | 648px (안전 수용) |
| 첫·마지막 슬라이드 중앙 정렬 padding | max(80px, calc(50% − 512px)) | max(80px, calc(50% − 348px)) |
| 좁은 뷰포트 (≤ 856px) 동작 | calc(100vw − 160) 적용 | 동일 (max-width만 줄어듦) |

## 일관성

v0.3.41~44에서 잡은 carousel-slider peek 스타일(첫·마지막 슬라이드를 viewport 정중앙에 두고 양옆 슬라이드를 살짝 peek) 패턴은 그대로 유지. wrapper padding과 item flex basis가 1024 → 696 동시 변경으로 peek 비율은 동일.
