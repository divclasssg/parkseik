# v0.3.55 — /projects/eum carousel-slider 첫·마지막 카드 그리드 정렬 (snap edge to section-content, peek full viewport)

## 작업한 내역

- `2026-05-20` `src/app/projects/_style/projects.style.scss`
    - `.carousel-slider`: `scroll-padding-inline: max(80px, calc(50% - 512px))` 추가 — snap 기준점을 section-content edge(50% ± 512)에 맞춤. carousel 컨테이너 자체는 full viewport 유지 → peek은 viewport edge까지 자유롭게 visible.
    - `.carousel-slider .slider-wrapper`: padding `max(80px, calc(50% - 348px))` → `max(80px, calc(50% - 512px))`. wrapper inset이 section-content 좌·우 edge와 일치하도록 변경.
    - `.carousel-slider .slider-wrapper .slider-item`:
        - `&:first-child { scroll-snap-align: start }` — snap rest 상태에서 첫 카드 좌측 edge를 section-content 좌측에 정렬.
        - `&:last-child { scroll-snap-align: end }` — snap rest 상태에서 마지막 카드 우측 edge를 section-content 우측에 정렬.
        - 중간 카드는 기존 `scroll-snap-align: center` 유지.

## 배경

v0.3.54에서 slider-item max-width를 1024 → 696으로 줄여 이미지(648)가 카드에 꽉 차게 했지만, wrapper padding `max(80px, calc(50% - 348px))` + 모든 카드 `scroll-snap-align: center` 설정은 모든 카드 center를 viewport center에 맞추는 peek 패턴을 유지함. 결과적으로 첫 카드 좌측 edge가 `50% - 348` 위치이고, 위 `section-content`(max 1024) 좌측 edge `50% - 512`보다 **164px 안쪽**으로 들어가 시각 그리드가 깨짐. 사용자 보고: "슬라이드 시작점이 안 맞다".

중간 시도(carousel-slider 자체를 1024로 바운드)는 정렬은 맞췄으나 옆 카드 peek이 1024 boundary에서 잘려 사용자가 "잘려 보이면 안 된다"로 재요청. 최종 해법은 carousel 컨테이너를 다시 full viewport로 두고 (peek가 viewport edge까지 자유롭게 visible), snap 기준점만 section-content edge에 맞추는 방식.

## 최종 해결 (carousel full V + snap edge 정렬)

- carousel-slider: width 변경 없이 full viewport 유지 → 옆 카드 peek가 viewport edge까지 자유롭게 visible.
- `scroll-padding-inline: max(80px, calc(50% - 512px))`: snap 기준점을 section-content edge에 맞춤.
- `slider-wrapper padding: 0 max(80px, calc(50% - 512px))`: wrapper inset도 section-content edge에 정렬.
- snap-align: first = start / middle = center / last = end → 3개 snap 포지션 [0, 556, 1112]에 깔끔 분포.

### Snap 포지션 검증 (V = 1920 기준)

| Card | snap-align | 목표 viewport 위치 | scroll-left |
| --- | --- | --- | --- |
| 1 (first) | start | 좌측 edge at 50% − 512 = 448 | **0** |
| 2 (middle) | center | center at 50% = 960 | **556** |
| 3 (last) | end | 우측 edge at 50% + 512 = 1472 | **1112** (= max) |

wrapper 폭 = 2 × 448 + 2136 = 3032. carousel 폭 = 1920. max scroll = 3032 − 1920 = 1112.

snap rest 상태에서 카드 정렬은 section-content edge와 일치 (≤ 1024 grid). 스크롤 도중에는 옆 카드들이 viewport edge까지 자유롭게 visible — 잘림 없음.

좁은 뷰포트(V ≤ 1184)에서는 padding이 80px로 clamp되며 동일 패턴 유지.

## JS 영향 (변경 불필요)

`goToSlide()`의 `scrollIntoView({ behavior: "smooth", block: "nearest", inline: "center" })`는 새 snap 환경에서도 자연 작동:

- **dot 1**: card 1 center 정렬 시도 → scroll-left −164 요청 → 0으로 clamp → snap-align: start 포지션과 일치.
- **dot 2**: card 2 center 정렬 → scroll-left 556 → snap-align: center 포지션과 일치.
- **dot 3**: card 3 center 정렬 → scroll-left 1276 요청 → max 1112로 clamp → snap-align: end 포지션과 일치.
