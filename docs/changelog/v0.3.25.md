# v0.3.25 — /projects/eum 히어로 animated WebP 화질 추가 향상

## 작업한 내역

- `2026-05-18` `eum/videos/hero/final_prototype_0{1,2,3}.webp` (R2) — v0.3.24의 animated webp를 더 높은 품질로 재인코딩하여 R2 덮어쓰기. 인코딩 옵션: `img2webp -q 88 -lossy -m 4` → **`-q 95 -mixed -sharp_yuv -m 6`**. 결과: 01 2.3MB → 3.1MB, 02 2.5MB → 3.9MB, 03 1.0MB → 1.4MB (총 5.8MB → 11MB, 약 1.9배). 새 ETag로 캐시 무효화 확인됨.

## 배경

v0.3.24로 디자인 방향(자동재생 motion + image 코덱) 정착 후 사용자가 "많이 좋아졌는데 조금 더 좋아져야 한다"고 응답. 동일 패턴을 유지하면서 화질만 끌어올리는 미세 조정.

옵션별 효과:
- `-q 95`: 양자화 강도 ↓ → 텍스트·세부 디테일 보존
- `-mixed`: frame별 자동으로 lossy/lossless 결정 → 텍스트 많은 frame이 lossless로 인코딩되어 더 깔끔
- `-sharp_yuv`: RGB → YUV 변환 시 chroma sharpening → 텍스트·아이콘 경계가 또렷
- `-m 6`: 압축 효율 최고 모드 → 같은 화질에서 파일 크기 ↓ (slow encoding)

코드 변경 없음(page.js는 동일 src를 가리킴). R2 객체만 덮어쓰기 → 사용자는 강력 새로고침(`Cmd+Shift+R`)으로 새 화질 확인.
