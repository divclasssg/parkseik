# v0.3.32 — /projects/eum hero 비디오 수직 호흡 공간 추가

## 작업한 내역

- `2026-05-19` `src/app/projects/eum/_style/projects.eum.scss` — `.video-wrapper`: `inset: 0` → `inset: 48px 0`. hero 안쪽에서 위·아래 48px씩 들여 프레임 가장자리와 hero 경계 사이에 호흡 공간 확보. 프레임은 `position: absolute; height: 100%; transform: translate(-50%, -50%)`로 wrapper에 상대 크기·중앙 정렬되므로, wrapper만 줄여도 프레임 전체가 자연스럽게 축소·재정렬됨. 주석도 갱신("hero 전체를 차지" → "hero 안쪽에서 위·아래 호흡 공간을 두고 차지").

## 배경

v0.3.31에서 hero를 flex column → absolute 오버레이로 재구성하며 `.video-wrapper { inset: 0 }`로 hero 전체를 채워 프레임 표시 폭을 ~1.5× 키웠음. 그 결과 프레임이 localnav 바로 아래(top edge)부터 section 바닥(bottom edge)까지 닿아 시각적 호흡이 없고 답답해 보이는 회귀 발생.

v0.3.31 changelog의 후속 메모("가독성 우려시 후속에서 phone-frame `height: 90%`로 조정")에서 예고된 조정이지만, 프레임 단위(`height: 90%`)가 아닌 wrapper 단위(`inset: 48px 0`)로 적용. 사유:

- 프레임 3종(phone-01, monitor-02, phone-03) 모두에 일괄 적용되도록 상위(wrapper)에서 처리 — 프레임별 분기 불필요.
- `inset`은 단일 라인 변경, 절대값(48px)이라 viewport 높이에 무관하게 일정한 호흡 공간 보장.
- 1080p 기준 hero 높이 ~872px → wrapper 높이 ~776px → phone-frame-01 폭 ~427 → ~380 CSS px(약 11% 축소). v0.3.31의 1.5× 확대 의도 대부분 보존하면서 답답함 해소.

`.section-content`(Eum 헤드라인 + 버튼)는 의도된 caption 오버레이 패턴이라 그대로 유지 — wrapper와 자연스럽게 겹쳐 디바이스 mockup 위 caption처럼 떠 있는 v0.3.31 디자인은 보존됨.
