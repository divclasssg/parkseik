## 배경

portfolio repo의 `/projects/eum`에는 Double Diamond Discover 섹션의 카드 3장에 R2 업로드된 리서치 자료 캡처 이미지가 연결되어 있었으나, parkseik/main 쪽은 `<div className="card-media"><picture></picture></div>` 빈 placeholder 상태였음. 두 repo가 동일 R2 origin(`pub-e26b73e054cf43faa65ef7ee77476e58.r2.dev/portfolio/...`)을 쓰므로 asset path를 그대로 재사용 가능.

portfolio는 `next/image` `<Image>`를 사용하지만 parkseik/main은 native `<picture>` placeholder가 이미 깔려 있어 marker에 맞춰 native `<picture><img>` + `asset()` 헬퍼 조합으로 통일.

## CSS 보완 이유

기존 규칙은 `.card-media { position: relative; picture { position: absolute; } }` 만 정의되어 있어 `<picture>` 안에 `<img>`를 넣어도 inset/width 미지정으로 0×0에 가까운 크기로 그려지는 문제가 있었음 (replaced element는 absolute+auto로 stretch되지 않음). 동시에 retina 환경에서 흐림이 발생하지 않도록 표시 폭을 소스 폭의 절반 이하로 캡(`max-width: 525px` — 3장 중 최소 소스 1050 ÷ 2).

`.card-tile .card-media`(Develop 섹션의 브레인스토밍 / MoSCoW / MVP 요약 카드 3장)는 여전히 빈 picture 상태로 두며, 기존 `height: 512px; align-items: flex-end` 규칙을 그대로 유지해 시각적 회귀 없음.
