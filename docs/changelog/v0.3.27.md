# v0.3.27 — /projects/eum 히어로를 mp4 video 자동재생으로 회귀

## 작업한 내역

- `2026-05-18` `src/app/projects/eum/page.js` — animated webp 패턴(v0.3.24~v0.3.26) 폐기, **v0.3.21 mp4 video 자동재생 패턴으로 복원**. `HERO_ITEMS`(단일 src/durationMs) → `VIDEOS`(src + srcLo + w/h/frame). `cycleN`/`setTimeout` cycle 로직 제거, 대신 `useRef` 3개 + `useHi` DPR 분기 state + `ended` 이벤트 리스너 cycle + `play()`/`pause()` useEffect. JSX의 `<img>` → `<video muted playsInline preload="auto">`. 자산 경로는 R2의 v0.3.20·v0.3.21 mp4 6개를 그대로 가리킴.

## 배경

v0.3.20부터 v0.3.26까지 7번에 걸쳐 화질 끌어올림을 시도했으나 v0.3.26 lossless animated webp에서도 사용자 만족 미달. 진단 결과 보유한 `final_prototype_*.mp4` 자체가 ffmpeg(`Lavf*`) 인코딩 결과 = 압축본이라 webp lossless가 이미 천장. 그 위에 어떤 옵션을 더해도 동일.

사용자 결정: 새 화면 녹화 없이 **mp4 video 자동재생 패턴으로 회귀** — 디자인 의도(자동재생되는 빠른 motion)를 우선시. 외장 1080p에서의 시간적 알리아싱은 trade-off로 수용.

R2 변경 0: v0.3.20·v0.3.21 시기에 올린 hi/lo mp4 6개(`portfolio/eum/videos/hero/final_prototype_0{1,2,3}{,_lo}.mp4`)가 그대로 살아있어 즉시 재활용.
