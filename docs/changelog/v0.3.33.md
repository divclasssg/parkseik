# v0.3.33 — /projects/eum hero 텍스트–비디오 겹침: frosted glass caption 활성화

## 작업한 내역

- `2026-05-19` `src/app/projects/eum/_style/projects.eum.scss` — `.section-content`(`.section-hero` 스코프) 라인 20–22에 주석 처리되어 있던 frosted glass 3종 규칙 활성화: `-webkit-backdrop-filter: saturate(180%) blur(20px); backdrop-filter: saturate(180%) blur(20px); background: rgba(255, 255, 255, 0.8);`. 블록 상단 안내 주석에도 frosted glass 의도 1줄 추가.

## 배경

v0.3.31에서 hero를 absolute 오버레이로 재구성하며 `.section-content`(Eum 헤드라인 + "환자와 의사를 이음." + 설명 + Demo 체험 버튼)를 비디오 프레임 하단에 caption처럼 얹는 패턴을 도입. 이때 `backdrop-filter` + 반투명 흰색 배경은 프로토타이핑은 됐지만 일단 주석 처리한 채 마감(`projects.eum.scss:20–22`).

v0.3.32에서 hero 위·아래 호흡 공간(`inset: 48px 0`)을 확보했음에도, 텍스트가 여전히 비디오의 하단 ~150–200px 위에 직접 얹혀 가독성 문제 잔존. 동영상은 밝은 색상의 UI + 빠른 움직임이라 흰 헤드라인·검은 본문·gradient 버튼 모두 어떤 프레임에선 묻히고 어떤 프레임에선 튐.

v0.3.31 changelog 라인 27이 이 회귀를 예고하며 두 가지 후속 옵션을 제시(`backdrop-filter: blur(8px)` 또는 `phone-frame { height: 90% }`). 본 버전은 전자 노선 — caption-over-mockup 디자인 의도를 유지하면서 가독성만 회복하는 방향 — 을 택함.

값은 코드베이스에 이미 검증된 frosted glass 패턴(`src/app/_style/_localnav.scss:24–29` `.content-collapsed-wrapper`의 `saturate(180%) blur(20px)` + `rgba(255, 255, 255, 0.8)`)과 정확히 동일하게 통일. 한 페이지에 localnav와 hero caption이 동시에 보일 때 톤 일치, 별도 토큰 신설 없이 일관성 확보.

레이아웃·`pointer-events` 정책·`.hero-body` max-width 1024px 등은 모두 그대로. `padding: 48px 0`을 포함한 padding-box 전 영역(좌→우 hero 전폭, 위→아래 ~280px)에 backdrop-filter가 적용되어 자연스러운 bottom 캡션 밴드 형성. 비디오 프레임은 frosted 영역에서 부드럽게 흐려져 보이되 완전히 가려지지는 않아 mockup-over-caption 분위기 보존.
