## 배경

v0.3.53~55에서 parkseik carousel-slider를 native CSS scroll-snap 기반으로 구성. 사용자 요청: "portfolio eum의 슬라이더를 참고해라". portfolio `_components/sectionDevelopWireframe.js`는 scroll-snap이 아니라 **JS 제어 translateX** 패턴을 사용:

- 컨테이너에 `overflow: hidden`
- 슬라이드 wrapper는 `display: flex` + `transition: transform 0.6s ease`
- `transform: translateX(calc(-${activeIndex} * (696px + 24px)))` 인라인 스타일로 activeIndex가 바뀌면 부드럽게 슬라이드
- `padding-left: calc((100vw - 1024px) / 2)` = section-content 좌측 정렬
- `padding-right: calc((100vw - 696px) / 2)` = 마지막 슬라이드 active 시 우측 잉여 공간

**결과 동작**: 모든 active 슬라이드는 좌측 edge가 section-content 좌측에 정렬됨. 우측은 다음 슬라이드 peek (또는 마지막일 때 빈 공간).

## 동작 검증 (V = 1920)

| activeIndex | translateX | 활성 카드 좌측 viewport 위치 | 우측 |
| --- | --- | --- | --- |
| 0 | 0 | 448 = section-content 좌측 | 카드 2, 카드 3 peek |
| 1 | −720 | 448 = section-content 좌측 | 카드 3 peek |
| 2 | −1440 | 448 = section-content 좌측 | 잉여 공간 (~776px) |

모든 활성 카드 좌측 edge = section-content 좌측 → 일관된 그리드 정렬. 우측 peek는 viewport edge까지 자유롭게 visible (overflow: hidden은 컨테이너 경계 = viewport edge이므로 잘림 없음).

좁은 뷰포트(V < 1184)에서는 padding이 80으로 clamp되며 동일 패턴 유지.
