## 배경

v0.3.33에서 활성화한 frosted glass caption이 사용자 검토 결과 부자연스럽다는 피드백. 세 가지 원인 동시 지적:

1. frosted band가 디바이스 mockup의 하단을 잘라먹어 디바이스 정체성 훼손.
2. 캡션이 디바이스 위에 올라온 패턴 자체가 portfolio 톤으로 어색.
3. frosted glass의 시각적 무게감(blur 20px + 반투명 흰색 배경)이 과함.

해결 방향은 overlay 구조(캡션이 hero 안에 absolute로 얹힘) 자체는 유지하되, **디바이스와 캡션의 시각적 겹침을 좌·우 분리로 해소**. 사용자 지시: "frosted제거. 영상 1,3번 우측으로 이동."

phone 프레임(01, 03)을 hero 우측으로 빼면, 좌·중앙의 캡션 텍스트 영역(`.hero-body` max-width 1024px 중앙 정렬)과 수평으로 분리되어 겹침이 사라짐. frosted glass 없이도 텍스트가 hero 배경(흰색) 위에서 또렷이 읽힘. 디바이스 mockup은 잘리지 않은 채 우측에 온전히 표시 → 정체성·존재감 회복.

monitor 프레임(02)은 사용자가 명시하지 않았고, 전폭 활용이 모니터 mockup의 시각 의도(데스크탑 화면 강조)이므로 중앙·전폭을 그대로 유지. monitor가 활성일 때 캡션이 모니터 하단을 가로지르는 건 monitor variant의 디자인 결정으로 수용. 1·3 phone variant 활성 시간(3:1 비율의 2/3)에서는 깔끔한 좌·우 분리가 유지됨.

구현은 `.phone-frame`과 `.monitor-frame`이 공유하던 positioning 규칙을 수평·수직으로 분리: 공통은 `top: 50%`만 남기고, phone에 `right: 0; translateY(-50%)`, monitor에 `left: 50%; translate(-50%, -50%)`를 각각 명시. video-wrapper inset(48px 0, v0.3.32)은 그대로 두어 위·아래 호흡 공간 보존.
