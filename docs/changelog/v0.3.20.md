## 배경

히어로 영상 3종이 알아볼 수 없을 만큼 흐리게 보임. 진단:

1. **소스 mp4 저비트레이트**: 1320×2868 @ 60fps가 3.2 Mbps로 권장(10–15 Mbps)의 1/3 수준.
2. **`playbackRate` 10x/5x 디코딩 과부하**: 60fps × 10x = 실효 600fps 디코딩 요구. 브라우저 디코더가 따라가지 못해 프레임 드롭/아티팩트.

CSS는 [[feedback_retina_media_cap]] 규칙(소스÷2)을 정확히 충족하여 손대지 않음. 대신 **배속을 소스 파일에 미리 굽고 60fps로 정규화**하여 디코더 부담을 1/N로 줄이는 방식 채택. 동일한 시각 효과 + 디코더 안정 + 파일 크기 1/10.
